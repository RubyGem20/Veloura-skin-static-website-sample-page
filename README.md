Veloura Skin – Static Website Sample

A responsive, static website demo for Veloura Skin, a fictional luxury skincare brand. This project focuses on clear structure, clean design, and fast performance, using only HTML, CSS, and minimal JavaScript.

Key features:

Modern, minimal UI tailored to a beauty/skincare brand

Responsive layout that works on mobile, tablet, and desktop

Product highlights, brand story, and contact sections

Optimized for quick loading and easy deployment (e.g., Netlify, Vercel, GitHub Pages)

Purpose:
Portfolio piece to demonstrate front-end skills, attention to branding, and the ability to build polished, production-style static sites for e-commerce and lifestyle brands.
